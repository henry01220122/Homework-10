# HTML 教學簡報使用方式

以 Chrome、Safari 或 Edge 開啟本資料夾的 [index.html](index.html)。簡報本身不需網路，查閱外部論文與文件時才需要連線。請保留整份 Wiki 的資料夾結構，才能使用各頁的本機筆記連結。

- 點選上一頁／下一頁，或用方向鍵翻頁。
- 頁面選單可跳到指定頁，Home／End 跳到首末頁。
- 第 8 頁的滑桿只解釋 Strength 概念，不會執行生圖。
- 第 11 頁可點選題目展開答案。
- 瀏覽器列印樣式已編寫，但實際列印分頁尚未驗證。

來源與頁面對照見 [outline.md](outline.md)，實際檢查範圍見 [validation.md](validation.md)。

這是本機 HTML 成果，尚未發布公開網址。作業要求的對外簡報連結仍需另行部署。
